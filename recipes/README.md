# Recipes

A recipe is a reusable, original design building block that `dazzle add <recipe>` copies into a project: for example a hero layout, a type scale, or a motion preset, wired to the project's levers.

Each recipe will live in its own folder, `recipes/<name>/`, as a workspace package. The folder format (manifest, files, lever bindings, preview and tests) is defined in Todo 3; this folder is empty until then.

Recipes must be original work. A recipe never reproduces a named site's design.
