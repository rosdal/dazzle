Dazzle

Design levers, a local studio and design checks for original sites built with Claude Code.

Nothing works yet: every command is a stub. This page will grow into the docs as features land.

Planned

  • An npm package, @rosdal/dazzle, with a Vite plugin and the dazzle CLI
  • A Claude Code plugin, released with the same version
npx @rosdal/dazzle --help

/plugin marketplace add rosdal/dazzle
/plugin install dazzle@rosdal

Intended use

Dazzle is for original sites only. It never clones a named site, and everything it generates in your project is yours.
